妈妈的消息

浏览器版

把聊天记录变成一个数字、一个标签、一句可以发出去的话。五步，不用装任何东西。

所有计算都在你的浏览器里完成，页面不向任何服务器发送你的记录。首次打开会下载一个 Python 运行时（约 10 MB，几个下载源自动选通的），下载过一次之后断网也能用。 写文字那一步需要你自己把提示词粘到任意 AI 里——粘到谁那儿，记录就发给了谁，这一点页面管不了。

1把记录放进来

导出文件（WeFlow / 留痕 / WeChatMsg 的 JSON、CSV、TXT）、她不一样的 messages.json、或者 AI 转录好的 JSON。编码（UTF-8 / GBK / UTF-16）自动识别。不知道怎么拿出来？看导出指南；只有截图的话，先让 AI 按指南里的格式转录成 JSON 再贴进来。

把文件拖到这里，或点击选择
时间按你这台电脑的时区解释；人在国外分析国内的记录，"几点找你"会偏。

3写文字

  
数字算完了，文字要靠 AI 写。回答三个问题（都可以跳过），复制提示词，粘到你常用的 AI（豆包 / Kimi / DeepSeek / Claude / ChatGPT），把它回的 JSON 粘回来。粘回来之后会按写作规矩查一遍：引号里的话必须是记录里真说过的，数字要能在 stats.json 里找到。

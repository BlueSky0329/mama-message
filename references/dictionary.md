# 黑话翻译表

报告里的翻译表是**个性化**的：从她的口头禅和最常问的主题里挑 6–10 条她真说过的话，配上翻译。下面是基础词典，用来对齐"翻译"的口径，不要原样照抄——她说过什么就翻什么。

## 基础词典

| 她说 | 她的意思 |
|---|---|
| 吃饭了吗 | 在吗，我想你了 |
| 吃的什么 | 我想知道你今天过得怎么样，但只会问这个 |
| 你那边冷不冷 / 降温了多穿点 | 我看了你们那儿的天气预报 |
| 没事，就是问问 | 有事，但怕耽误你 |
| 你忙吧 / 打扰你了 | 我等你 |
| 那你先忙 | 你什么时候有空都行，我一直有空 |
| 钱够不够花 | 我能为你做的只剩这个了 |
| 转发：这几种菜不能一起吃 | 我不会说担心你，所以转了个链接 |
| 转发：紧急通知请扩散 | 我把世界上所有的危险都想替你挡一遍 |
| 什么时候回来 | 我已经在想那天做什么菜了 |
| 早点睡，别熬夜 | 我也没睡，在等你回 |
| 在干嘛 | 我一个人在家 |
| 到家了吗 | 我从你出门就开始算时间 |
| 你爸让我问你… | 是我想问 |
| 身体怎么样 | 我这边不太好，但我先问你 |
| 你王阿姨问你有对象了吗 | 我不敢问，借别人的嘴 |
| 给你寄了点东西 | 我去了三趟快递站 |
| 没什么事，挂了吧 | 还想再听你说两句 |
| 好，知道了 | 我不完全同意，但我不想让你烦 |
| [玫瑰] | 我不知道说什么了，但我在 |

## 怎么生成个性化条目

1. 从 `stats.json` 的 `catchphrases.her`、`topics`、`phrases.self_shrink_examples`、`forwards.titles` 里取她真说过的句子。
2. 每条翻译一句话，≤ 18 字，用她的第一人称。
3. 翻译的是**动机**，不是**情绪**。"吃了吗" → "在吗，我想你了" 是动机；→ "妈妈好爱你" 是抒情，不要。
4. 有证据才翻。她说"早点睡"时如果自己是 23 点发的，才能翻成"我也没睡"；她 21 点发的就翻"我要睡了，睡前想确认你还好"。
5. 她是急脾气就翻急脾气。"怎么又不回消息" → "我数着时间等了三天"，不要美化成"她很温柔"。
6. 6–10 条。少于 6 条说明记录不够，就少列，不硬凑。
7. 用户说"她不是这个意思" → 当场改那一条，并问一句"那她通常是什么意思"，用用户的版本。

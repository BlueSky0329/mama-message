# 报告模板

两份输出：对话里的 Markdown 报告（下面的模板）和 `narrative.json`（喂给 `render.py` 出 HTML）。数字从 `stats.json` 取，文字按 `writing-rules.md` 写。称呼和"她/他"按确认的对象替换。

## 对话里的 Markdown 报告

```markdown
# 妈妈的消息 · [标题，如"你和妈妈的半年"]

[起] 至 [止] · [N] 天 · 共 [M] 条（她 [a] / 你 [b]）
[节日] 还有 [x] 天

💛 牵挂指数   [xx] [██████░░░░]  [一句话：她发起了 xx% 的对话，其中 xx 条在早上 8 点前]
🧊 嗯哦好指数 [xx] [████░░░░░░]  [一句话：你 xx 条回复不超过三个字，最长 xx 没回]
🕰️ 不计较指数 [xx] [█████████░]  [一句话：你没回的 xx 次里，有 xx 次是她自己先开口了下一次]

## 六个数字
1. 谁先开口 —— 她 [x] 次 / 你 [y] 次
2. 你回她，通常要 —— [中位]（最长一次隔了 [时长]，她那条是"[原文]"）
3. 她最长的一条 —— [字数] 字："[摘要]" ／ 你回了 [字数] 字："[原文]"
4. 你的"嗯 / 好 / 知道了" —— [n] 条，占你全部回复的 [p]%（嗯×8、好×7…）
5. 她最常问的三件事 —— ① [主题] [次]"[原话]" ② … ③ …
6. 她最常在 —— [时段] 找你；你最常在 [时段] 回

## 她的消息成分表
[主题] xx% · [主题] xx% · 表情包 xx% · 语音 xx% · 转发文章 xx%
她最常发的表情：[玫瑰] xx 次、[握手] xx 次 · 口头禅："…""…"

## 鉴定结果
她：[类型]（副型：[类型]）—— [引 2–3 句原话 + 一个数字]
你：[类型] —— [引你的回复 + 次数]
综合评级：[五档之一]

## 她的黑话翻译表
"[她的原话]" → [翻译]
（6–10 条）

## 节日记分牌
[节日] · [谁] [时间] 先发的："[内容]" · 她 x 条 / 你 y 条
[节日] · 那天你们没说话

## 她发了，你没回
- [日期] "[原文]"（最多 5 条）

## 她转给你的
[一句话：转了 N 篇，M 篇养生，和你 x 月说过的 xx 有关；你回了 y 篇]

## 该打电话了
🔴 …
🟡 …

## 她其实想说的是
[2–3 段，120–220 字]

## 你可以今晚就做的三件事
1. …
2. …
3. …

## 帮你回
回 [日期 "原话"]：[一句]
（3 条）

## 三句打电话的开场白
📞 "…" —— [为什么]
（3 条）

## 亲情账单
她发给你 [N] 条 ／ 你回她 [M] 条 ／ 她发了你没回 [U] 次 ／ 通话 [C] 次
结余：欠 [U] 条回复、1 个电话

## 可以直接发给她的一条
[60–100 字]

---
数据说明：基于 [N 张截图 / 导出记录]，[x] 条有时间戳；回复间隔基于 [y] 对相邻消息取中位数；语音不计字数；转账只记次数；[截图有断层的话写在这里]。这是一份统计，不是评判。
```

## narrative.json

`render.py` 读这些字段，缺哪个就在 HTML 里显示〔待写〕。

```json
{
  "title": "你和妈妈的半年",
  "index_lines": {"care": "…", "short": "…", "forgive": "…"},
  "type_lines": {"mother": "…", "child": "…"},
  "dictionary": [{"her": "吃饭了吗", "means": "在吗，我想你了"}],
  "forward_insight": "…",
  "she_means": "第一段\n第二段\n第三段",
  "tonight": ["…", "…", "…"],
  "replies": [{"to": "08-25 “中秋回来吗”", "draft": "…"}],
  "call_openers": ["“…”——为什么", "…", "…"],
  "bill_balance": "欠 59 条回复、1 个电话",
  "send_text": "妈，我用了个软件……今晚 8 点打给你。",
  "send_cta": "中秋还有 26 天",
  "child_call": "的儿子",
  "cta": "今晚 8 点，打个电话",
  "footnote": "数据说明"
}
```

`index_lines`、`forward_insight`、`bill_balance`、`send_cta`、`cta`、`footnote` 不写会用默认值（从 stats 自动拼）。其余必须写。

## 生成命令

```bash
python scripts/stats.py messages.json --out stats.json --today 2026-08-30 --her-birthday 10-20 --my-birthday 06-03
# 读 stats.json，写 narrative.json
python scripts/render.py stats.json narrative.json --out reports/
```

产出 `reports/mama-message-report.html`（完整报告）、`mama-message-card-bill.html`（亲情账单卡）、`mama-message-card-send.html`（发给她的卡）。告诉用户用浏览器打开、截图。
